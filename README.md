# Habit RPG (습관 추적기)

브라우저에서 쓰는 **습관 체크·통계 앱**입니다. Next.js로 만들었고, 데이터는 기본적으로 이 기기의 **브라우저 저장소(localStorage)** 에 남습니다.

## 어떤 앱인가요?

- **오늘의 습관**: 추가한 습관을 날짜별로 완료 체크합니다.
- **연속 일수·요약**: 오늘·주간 달성률, 최장 연속 등을 한눈에 봅니다.
- **월별 히트맵**: 이번 달 얼마나 채웠는지 색으로 표시합니다.
- **랜딩 페이지**: 소개용 화면은 `/landing` 경로에서 볼 수 있습니다.

별도 회원가입 없이 바로 쓸 수 있고, **저장** 버튼을 누르면 이름 입력 후 로컬에 백업하고, 설정되어 있으면 Google(Firebase) 연동 저장을 시도합니다. Firebase 환경 변수가 없으면 안내 메시지와 함께 로컬 저장만 됩니다.

## 시작하기 (로컬 실행)

1. [Node.js](https://nodejs.org/) LTS 설치
2. 프로젝트 폴더에서:

```bash
npm install
npm run dev
```

3. 브라우저에서 **http://localhost:3000** 을 엽니다.  
   3000번 포트가 이미 쓰이면 터미널에 나온 주소(예: 3001)를 사용하세요.

## 사용 방법 (앱 안에서)

1. **습관 추가**에 이름을 넣고 추가합니다.
2. **오늘 목록**에서 완료한 항목을 눌러 체크·해제합니다.
3. 아래 **히트맵**으로 이번 달 패턴을 확인합니다.
4. 데이터를 남기려면 **저장하기**를 누릅니다. 처음에는 짧은 이름 입력 창이 뜰 수 있습니다.

Google 클라우드 연동을 쓰려면 `.env.local` 등에 Firebase 관련 `NEXT_PUBLIC_*` 변수를 넣어 두면 됩니다. 없으면 로컬 저장만 동작합니다.
